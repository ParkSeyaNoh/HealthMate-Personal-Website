HealthMate: AI-Based Health Prediction and Medicine Recommendation System for Barangay Health Offices

Thesis Abstract & Purpose

HealthMate bridges municipal healthcare facilities and local citizens through a unified, data-driven ecosystem. By synthesizing a native Android clinic administration app, a frictionless public web portal, real-time Cloud Firestore stock synchronization, and XGBoost machine learning for outbreak forecasting, the system resolves delayed epidemic detection and unexpected medicine shortages in community health centers.

Priority Architecture

Core Features of HealthMate

Directly addressing rural health unit bottlenecks through automated prediction, live tracking, and accessible interfaces.

📊
Predictive Analytics

XGBoost Disease Outbreak Forecasting

Analyzes historical patient case reports, symptomatic indicators, and seasonal epidemiological patterns with a Python XGBoost model to predict community disease surges up to two weeks in advance.

💊
Supply Intelligence

Real-Time Medicine Inventory Tracking

Maintains live batch tracking, stock counts, expiry thresholds, and consumption velocity across the clinic. Automatically alerts healthcare personnel prior to stock depletion so replenishment orders are placed on time.

🔄
Dual-Access Ecosystem

Two-Way Cloud Firestore Synchronization

Actions performed on the frontline Android admin app (such as dispensing medicine or logging consultations) instantly synchronize with Cloud Firestore to update public medicine availability indicators in real-time.

🔐
Security & Integrity

Role-Verified Firebase Access

Protects administrative controls and patient privacy. Secure verification through Firebase Authentication cross-referenced with the Firestore collection ensures only verified BHWs, nurses, and doctors can alter records.

Public Community Facing

Citizen Public Health & Inventory Web Page

The HealthMate Web Page is a zero-friction, browser-accessible portal designed for community residents, outpatients, and families. Residents can immediately check medicine availability and advisories without traveling to the clinic.

Target Users: Barangay Residents General Public

What Citizens Can Do on the Web Page:

  • Check Live Medicine Stocks: Look up prescribed medications in real time to see if they are in stock at the local health unit before leaving home.
  • Read Community Outbreak Advisories: Access timely health warnings and preventive tips driven by the system's XGBoost prediction models.
  • Zero Installation Required: Read-only access optimized for any smartphone browser with minimal mobile data usage.

Healthcare Personnel Only

Admin & BHW Android Mobile Application

The HealthMate Admin App is a secure native Android mobile command center built for municipal clinic operations, field consultations, and real-time inventory management.

Target Users: Municipal Doctors Clinic Nurses Barangay Health Workers (BHWs) Inventory Custodians

What Health Personnel Do in the Admin App:

  • Patient Consultation & Symptom Logging: Frontline workers log patient demographic data, symptoms, and diagnoses. This anonymized data directly feeds the Python XGBoost outbreak forecasting model.
  • Real-Time Stock Dispensation & Auditing: Deduct medicines upon dispensing with instant Cloud Firestore updates; log newly delivered supply batches and expiry dates.
  • Health Records Management: View past health trends and risk assessments and upload new medical information.
  • Multi-Tiered Role Verification: Authenticated accounts are verified against the Firestore collection to restrict administrative actions to authorized personnel only.
